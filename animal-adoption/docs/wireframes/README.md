# Application Wireframes

This directory contains the wireframe designs for the 3 main screens of the Animal Adoption platform, satisfying Part E Step 2.

## Screens Overview

1. **Screen 1: Animal Listings View (`/animals`)**
   - **File**: [`screen1-animals-list.svg`](./screen1-animals-list.svg)
   - **Key Elements**: Search bar, species filter dropdown, tag filter dropdown, sort selector, animal card grid with status and owner metadata, pagination controls.

2. **Screen 2: User / Shelter Profile View (`/accounts/:id`)**
   - **File**: [`screen2-account-view.svg`](./screen2-account-view.svg)
   - **Key Elements**: Account header (avatar, name, role badge, phone, contact notes, location), list of available animals posted by this user, empty state handling, banned state warning.

3. **Screen 3: Animal Detail View (`/animals/:id`)**
   - **File**: [`screen3-animal-detail.svg`](./screen3-animal-detail.svg)
   - **Key Elements**: High-res animal photo, tags, personality details, adoption requirements, owner/shelter card link, inquiry CTA button.
